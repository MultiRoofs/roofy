# Roofy motion studies

Open `/brand/motion/index.html` on the dev server to compare and replay the three directions.

- **A — Build, roof by roof:** 1.8 seconds, foundation then roof planes. Recommended brand signature.
- **B — Horizon reveal:** 1.6 seconds, a quiet upward reveal.
- **C — Open possibilities:** 2 seconds, planes expand from their shared edges.

Each direction has a `-light.svg` and `-dark.svg` asset for the corresponding background. SVGs have transparent backgrounds, run once, hold the original mark, and disable animation with `prefers-reduced-motion`. Embed with an image element or inline SVG in a browser; static viewers may display only the final mark. They are scalable mark-only assets, with no font dependency. The preview pairs them with the current Source Sans 3 wordmark. They are proposals, not a replacement of the application's logo.

Motion is an explicitly requested exception to the static brand kit's no-effects rule. Original coordinates and fill colors are retained at rest. No palette or static logo files have been changed.
