# Suggested Commands

## Development
- `npm run dev` — Start Vite dev server
- `npm run build` — TypeScript compile + Vite build
- `npm run preview` — Preview production build

## Testing
- `npm test` — Run all tests once (vitest run)
- `npm run test:watch` — Run tests in watch mode

## Code Quality
- `npm run lint` — Run ESLint
- `npm run format` — Format with Prettier (write)
- `npm run format:check` — Check formatting without writing

## DevContainer
- `npm run devcontainer:up` — Start devcontainer (Docker)
- `npm run devcontainer:up:podman` — Start devcontainer (Podman)
- `npm run devcontainer:shell` — Attach shell to container

## System Utilities (macOS / Darwin)
- `git` — version control
- `ls`, `find`, `grep` — file system navigation/search
- `node`, `npm` — Node.js runtime and package manager
